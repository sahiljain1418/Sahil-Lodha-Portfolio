# Sahil Lodha — Portfolio V1

A photo-led personal portfolio built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Deploy

Upload this project's contents to your GitHub repository and import that repository into Vercel.

## Important

Before publishing publicly, open `HOW-TO-EDIT.md` and:
- add your LinkedIn URL
- add your email
- add your resume
- add the missing IMPELz video and role/dance photos
- review every metric and public-facing internship visual
